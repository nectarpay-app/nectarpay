🍯 NectarPay Pro (v2.0.1)

Welcome to the official repository for NectarPay Pro – a sleek, high-performance desktop wallet and payment management application designed to streamline digital asset handling, coordinate multi-method global transfers, and maintain synchronized transaction tracking.
Built with a responsive, modern glassmorphic web interface and a robust Python desktop backend server, NectarPay Pro provides an integrated financial hub straight to your local operating system.

🚀 Key Features
1. Expanded Transfer Matrix: Directly execute transfers through multiple secure lanes, including Nectar, PayPal, CashApp, Bitcoin, Apple Pay, and Bank Wire.
2. Enhanced Transaction Security: Integrated dynamic Math CAPTCHA verification layer designed to authorize transfers and safeguard against accidental processing.
3. Instant UI Synchronization: Fully asynchronous transaction handlers that instantly update available balances across your dashboard and virtual card modules without requiring a system refresh.
4. Virtual Card Facility: View, track, and dynamically toggle the freeze state of your secure virtual Nectar Card directly from the localized wallet workspace.
